# Previewer

Референс-менеджер для Windows на Python и PySide6. Окно можно закрепить поверх других окон, в нём собирают референсы
на холсте с сеткой, рисуют, вырезают участки картинок и заменяют их. Работает локально.

## Возможности

- **Закрепление поверх окон** и тёмный интерфейс.
- **Проекты:** папки → проекты → рабочие окна. Всё можно создавать, переименовывать и сворачивать.
- **Холст с сеткой** (шаг 40 px) и «магнитом»: край картинки прилипает к линии, когда подходит к ней близко.
- **Картинки в полном разрешении:** перетаскивание файлов, вставка из буфера (Ctrl+V). Оригиналы хранятся без потерь.
  Растягивание за 8 маркеров, как в Photoshop: Shift — переключить сохранение пропорций, Alt — от центра, Ctrl — без привязки.
  Размер можно задать числами (Ш×В) с «привязкой в соотношении».
- **Кисть и ластик** с выбором цвета и толщины, отмена и повтор.
- **Обрезка:** свободная, по стандартным соотношениям и по размерам Gemini 3 Pro Image (1K и 2K).
  Результат копируется в буфер обмена, файл не меняется. Размеры Gemini лежат в `ratios.json` и правятся без кода.
- **Участки.** Каждое копирование рамки записывается в список (по разделам-картинкам). Участок можно заменить куском из
  буфера или файла: кусок подгоняется по пикселям. У каждой замены есть история из трёх последних итераций и глазик
  (показать вставку или исходный участок). Белый фон вставки автоматически становится прозрачным.
- **Замена основной картинки** из буфера или файла, с той же историей.
- **Экспорт в Photoshop (PSD)** выбранной картинки: нижний слой — картинка, выше — актуальные вставки участков.

## Установка и запуск

Нужен Python 3.10+.

```
pip install -r requirements.txt
python main.py
```

Либо двойной клик по `run.bat`.

## Где лежат данные

Проекты, картинки и настройки сохраняются в папке `data/` рядом с программой. В репозиторий она не входит.

## Структура

- `main.py` — запуск.
- `refmanager/` — код: окно, холст, элементы холста, обрезка, участки, экспорт PSD, хранилище проектов.
- `ratios.json` — стандартные соотношения сторон и размеры Gemini.
